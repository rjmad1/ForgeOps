# Security Policy

## Supported Versions

We actively support and patch the following versions of ForgeOps:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | ✅ Yes (Active)     |
| < 1.0   | ❌ No              |

## Reporting a Vulnerability

We take the security of ForgeOps seriously. If you find a security vulnerability, please do not report it in a public GitHub issue. Instead, follow these steps:

1. **Email us**: Send a detailed report to **security@forgeops.io**.
2. **Details to include**:
   - Description of the vulnerability and its potential impact.
   - Step-by-step instructions or proof-of-concept (PoC) code to reproduce it.
   - Any details about your host environment.
3. **Response time**: We will acknowledge receipt of your report within 48 hours and provide a primary contact for coordinated resolution.

## Our Disclosure Process

- Once a vulnerability is verified, we will work on a patch to resolve it.
- We will coordinate the release of the patch and a public Security Advisory (CVE) within a reasonable window (typically 90 days from the initial report).
- We ask reporters to respect this coordinated disclosure timeline and not publish information about the vulnerability until the patch has been released.
