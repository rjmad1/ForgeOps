# Configuration Schema: AI Runtime Manager

AI Runtime Manager automates all downstream configurations. Users should never edit YAML configuration files directly. The Configuration Manager synthesizes all files.

## Orchestrator Configuration

The orchestrator itself is configured using a master `arm-config.yaml` file stored in the application directory.

```yaml
# arm-config.yaml
orchestrator:
  host: "127.0.0.1"
  port: 8088
  db_path: "C:\\ProgramData\\AIRuntimeManager\\arm.db"
  log_level: "info"
  health_check_interval_seconds: 10
  metrics_poll_interval_seconds: 5

runtimes:
  ollama:
    enabled: true
    port: 11434
    binary_path: "C:\\Users\\rjkum\\AppData\\Local\\Programs\\Ollama\\ollama.exe"
    models_dir: "C:\\Users\\rjkum\\.ollama\\models"
  litellm:
    enabled: true
    port: 8000
    host: "127.0.0.1"
  openclaw:
    enabled: true
    port: 8080
    host: "127.0.0.1"
```

## Programmatically Synthesized Configurations

### 1. LiteLLM Configuration (`litellm-config.yaml`)
Synthesized by the `LiteLLMPlugin` based on models discovered from Ollama and user alias registrations.

```yaml
# Auto-generated by AI Runtime Manager Configuration Engine. DO NOT EDIT.
model_list:
  - model_name: codegemma
    litellm_params:
      model: ollama/codegemma
      api_base: http://localhost:11434
  - model_name: llama3
    litellm_params:
      model: ollama/llama3
      api_base: http://localhost:11434
  - model_name: text-embedding-3-local
    litellm_params:
      model: ollama/nomic-embed-text
      api_base: http://localhost:11434

general_settings:
  master_key: "arm-local-token-secure"
  cors_allowed_origins: ["*"]
  disable_master_key_check: false
```

### 2. OpenClaw Configuration (`openclaw-config.yaml`)
Generated programmatically to target the local LiteLLM gateway.

```yaml
# Auto-generated by AI Runtime Manager Configuration Engine. DO NOT EDIT.
server:
  host: 127.0.0.1
  port: 8080

gateway:
  openai_api_base: http://localhost:8000/v1
  openai_api_key: arm-local-token-secure
  default_model: llama3
```

## Subprocess Environment Variables

When spawning subprocesses, the Process Manager injects the following Windows Environment variables:

- **Ollama Process**:
  - `OLLAMA_HOST=127.0.0.1:11434`
  - `OLLAMA_MODELS=C:\Users\rjkum\.ollama\models`
- **LiteLLM Process**:
  - `LITELLM_LOG=INFO`
  - `PORT=8000`
  - `HOST=127.0.0.1`
